# Apteka Order Manager – облачна версия

Заявки за лекарства за аптека. Данните са в Supabase (Франкфурт, ЕС), затова
всеки компютър работи сам, без значение дали главният е включен.

Отваряне / инсталиране: https://velislav1.github.io/apteka-order-manager/

- `index.html` – програмата (една икона; ролята идва от акаунта, одобрен от Главния).
- `app.js`, `app.css` – самата програма (обща за трите роли).
- `supabase/schema.sql` – базата, потребителите и правата.
- `tools/prenesi-starite-danni.js` – пренася заявките от старата (флашка) версия.

В кода има само публичния (publishable) ключ. Защитата е в базата: без одобрен акаунт
нищо не може да се чете, а заявките мести само „Главен“.
